# Notes App

A multi-user Android notes application built with Java and SQLite.

## Features

- Secure sign-up and sign-in
- Add, view, edit, delete, and share notes
- Mark and unmark notes as favorites
- Search notes by title or content
- Categorize and filter notes using tags
- Sort notes alphabetically or by creation date
- View and edit user profiles
- Remember email and sorting preferences

## Download

Download the latest APK from the [Releases](../../releases/latest) page.

## Run from Source

1. Clone the repository:

   ```bash
   git clone https://github.com/Razan-Shalabi/Notes-App.git
   ```

2. Open the project in Android Studio.
3. Wait for Gradle synchronization to complete.
4. Run the application on an emulator or a physical Android device.

## Tech Stack

- Java
- SQLite
- Android SDK
- Material Design components
